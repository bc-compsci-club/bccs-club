# Brooklyn College Computer Science Club Website

## Tech Stack

- Frontend:
  - TypeScript (JavaScript)
  - Next.js (React.js)
  - Tailwind CSS
- Backend:
  - Java
  - Spring Boot
- Database:
  - PostgreSQL
- Deployment:
  - Docker
  - Linux
- CI/CD:
  - GitHub Actions

## Run the project showcase

From `frontend/`, run `npm ci` and `npm run dev --demo` to preview 23 examples without a database. Open [localhost:3000/showcase](http://localhost:3000/showcase).

For database-backed development or deployment, see the [frontend setup](frontend/README.md), [project upload guide](docs/upload-showcase-project.md), and [database operations guide](docs/database-operations.md).

Administrators can [delete a showcase project by ID](docs/delete-showcase-project.md).
